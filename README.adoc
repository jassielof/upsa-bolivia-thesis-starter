Repositorio de inicio para preparar un trabajo de grado con Typst. Contiene documentos de ejemplo, carpetas para recursos y tareas de compilación. Es un proyecto para evaluación y uso voluntario; no implica aprobación oficial de la Universidad.

== Primeros pasos

. Copiá este repositorio o creá uno desde el botón _Use this template_ de GitHub.
. Si usás Git, clonalo con los submódulos para incluir la plantilla:
+
[source,shell]
----
git clone --recurse-submodules <URL-de-tu-repositorio>
----
+
Si ya lo clonaste, ejecutá `git submodule update --init --recursive`. Si descargás un ZIP, asegurate de incorporar también el contenido del submódulo `template`; el ZIP del repositorio principal no lo incluye.
. Instalá Typst y, para usar las tareas incluidas, Task. Conservá las fuentes necesarias en `assets/fonts` y verificá sus licencias.
. Abrí el documento que quieras preparar, reemplazá los datos del ejemplo y compilalo desde la raíz del repositorio.

La configuración de parámetros, funciones y estilos se explica en el link:template/upsa-bo/README.md[README de la plantilla]. Este archivo describe el uso del kit.

== Documentos y compilación

[cols="1,2,1",options="header"]
|===
|Documento |Archivo principal |Tarea
|Trabajo de grado |`documents/thesis/TFG.typ` |`task thesis`
|Plan de trabajo |`documents/plan/TFG-PLAN.typ` |`task plan`
|Estudio de factibilidad |`documents/feasibility/study.typ` |`task study`
|Resumen |`documents/abstract/abstract.typ` |`task abstract`
|Cubierta |`documents/book/front-cover.typ` |`task front-cover`
|Lomo |`documents/book/spine-cover.typ` |`task spine-cover`
|Currículum |`documents/cv/CV.typ` |`task cv`
|===

`task` ejecuta las tareas principales; el estudio de factibilidad se genera por separado con `task study`. Consultá `Taskfile.yaml` para ver los comandos y destinos de salida. Las tareas que no indican un destino explícito generan el PDF junto al archivo fuente.

También podés compilar directamente con Typst, indicando la raíz y las fuentes. Por ejemplo:

[source,shell]
----
typst compile --root . --font-path assets/fonts documents/plan/TFG-PLAN.typ
----

== Recursos y entorno de trabajo

* `assets/fonts`: archivos de las fuentes necesarias y sus licencias. Las fuentes instaladas en tu equipo pueden no estar disponibles en otro equipo o en el editor web.
* `assets/images`: imágenes y otros recursos gráficos.
* `data`: archivos de datos utilizados por los ejemplos.
* `template`: submódulo que contiene la plantilla y su documentación.
* `.vscode`: ajustes y extensiones recomendadas para trabajar en VS Code.

Para probar el kit en el editor web de Typst, incorporá los archivos del proyecto, el contenido del submódulo y las fuentes utilizadas, conservando las rutas. Las tareas de Task y GitHub Actions corresponden al entorno local o de automatización; no se ejecutan dentro del editor web. La compatibilidad de los ejemplos debe comprobarse en ese entorno.

== Estado de los ejemplos

Los ejemplos ilustran configuraciones que deben revisarse con tu carrera o asesor. La selección tipográfica está pendiente de revisión académica; los valores incluidos no acreditan autorización institucional.

El ejemplo por partes refleja una organización particular del proyecto. La configuración por capítulos como opción predeterminada y el ajuste de su jerarquía de encabezados están pendientes. Si la exportación PDF/UA informa un error de niveles de encabezados, revisá la estructura; no desactives las comprobaciones para tratar el resultado como accesible.

== Guardado y revisión

Podés guardar el proyecto en una carpeta de OneDrive o Google Drive, conservando sus archivos y rutas. Evitá editar simultáneamente el mismo archivo fuente y guardá las versiones PDF enviadas al asesor con nombres identificables.

Git es opcional y permite conservar un historial más preciso de cambios. El asesor puede revisar el PDF sin utilizar Git ni Typst.

== Compilación en GitHub Actions

El flujo incluido compila los documentos y configura la carga de `out` como artefacto descargable desde la ejecución de Actions. No publica los documentos en GitHub Pages. Si agregás documentos o cambiás sus destinos de salida, verificá que la ruta del artefacto incluya los PDF que quieras descargar.

== Dudas y problemas

Usá _Issues_ para informar errores del kit y _Discussions_, si está habilitado, para consultas. Incluí el comando utilizado, la versión de Typst y el mensaje de error, evitando compartir datos personales o contenido reservado del trabajo.
